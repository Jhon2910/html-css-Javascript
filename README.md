## 📚 Tópicos Estudados & Aplicados

- **HTML5 Semântico:** Estruturação acessível, tags semânticas, formulários, tabelas e iframes.
- **CSS3 Moderno:** Flexbox, CSS Grid, Variáveis CSS, Glassmorphism, Dark/Light Mode, Design Responsivo (Mobile-First).
- **JavaScript Moderno:** Manipulação do DOM, Eventos, Consumo de APIs com `Fetch` / `Async-Await`, LocalStorage.
- **Back-end & Integração:** Spring Boot (Java), criação de endpoints REST, persistência com banco de dados.
