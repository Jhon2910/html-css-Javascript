# Roadmap

## MVP

### Fase 1 — Estrutura inicial
- [x] Criar a estrutura do projeto.
- [x] Configurar o ambiente de desenvolvimento.
- [x] Configurar o Node.js e o banco de dados SQLite.
- [x] Criar a página inicial do sistema.

### Fase 2 — Cadastro de chamados
- [x] Criar formulário de cadastro.
- [x] Adicionar campos de título, descrição e categoria.
- [x] Validar os dados obrigatórios.
- [x] Implementar o armazenamento dos chamados no banco de dados.
- [x] Definir o status inicial automático como "Aberto".

### Fase 3 — Consulta de chamados
- [x] Implementar a listagem de chamados.
- [x] Exibir informações principais dos chamados.
- [x] Implementar a consulta visualizando os detalhes completos de um chamado.

### Fase 4 — Atendimento
- [x] Implementar a funcionalidade de alteração de perfil na interface (Funcionário / Suporte).
- [x] Implementar a atualização de status restrita à equipe de suporte.
- [x] Implementar o registro de informações de atendimento (descrição, data e responsável manual).
- [x] Permitir a adição de múltiplos registros de atendimento para formar um histórico.

## Pós-MVP
- Autenticação e perfis reais de usuário.
- Prioridade e categorias avançadas dos chamados.
- Anexos e sistema de comentários.
- Notificações por e-mail.
- Dashboard gerencial e relatórios avançados.
- Integração com outras plataformas corporativas.
